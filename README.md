## ✨ Про проєкт

> *«synapse — особистий онлайн-портал шкільних робіт та навчання. Я створив його щоб вчителі могли зручно переглядати стилізовані та оригінальні роботи онлайн, замість неякісної писанини у зошиті.»*  
> — **Данило Павлюк**, автор проєкту

**synapse** переосмислює підхід до виконання та здачі навчальних завдань. Замість поспіхом списаних зошитових сторінок, нерозбірливого почерку та фотографій низької якості, кожна робота перетворена на структуровану, приємну для читання веб-сторінку.

Портал поєднує академічний зміст із сучасними стандартами вебу: виразною типографікою, індивідуальними колірними палітрами для кожного предмета, інтерактивними таблицями та адаптивністю для будь-яких пристроїв.

## 🌟 Ключові особливості для користувача

* 🎨 **Індивідуальна візуальна айдентика предметів:**
  * 🌿 **Біологія** — глибокі смарагдові акценти природи та життя.
  * 🌍 **Географія** — виразні картографічні та морські відтінки синього й пісочного.
  * ✍️ **Українська мова** — тепла сонячна золотисто-медова палітра.
* 🌓 **Темна та світла теми:** автоматичне визначення системної теми або перемикання вручну в один клік із плавним анімованим переходом та збереженням у пам'яті браузера (`localStorage`).
* ⚡ **Миттєве завантаження (SPA):** швидкі переходи між роботами без перезавантаження сторінки завдяки React Router.
* 📱 **Абсолютна адаптивність:** комфортне читання зі смартфонів, планшетів, ноутбуків та широкоформатних моніторів.
* 📊 **Багате оформлення матеріалів:** структуровані картки, порівняльні таблиці, виділені висновки та цитати відомих науковців і діячів.
* 🔗 **Прямі посилання на кожне завдання:** вчителеві достатньо надіслати єдине посилання, щоб відкрити конкретну лабораторну чи реферат.

> *«Карти — це найвеличніші поеми, написані лініями та кольорами.»* *(Ґілберт Гросвенор)*

* **Нідерланди:** комплексне країнознавче дослідження в межах проєкту «Країни Європи».
* **Вторинний сектор економіки:** класифікація та просторова організація переробної промисловості світу.
* **Рекреаційні ресурси Європи:** курортний потенціал, туристична інфраструктура та третинний сектор.

## 🚀 Локальне розгортання та запуск

### Вимоги
* Встановлений [Node.js](https://nodejs.org/) (версії `18.x` або вище)
* Пакетний менеджер `npm`, `pnpm` або `yarn`

### Кроки для запуску:

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/kasatjk/synapse.git
   cd synapse
   ```

2. **Встановіть залежності:**
   ```bash
   npm install
   ```

3. **Запустіть середовище розробки:**
   ```bash
   npm run dev
   ```
   *Додаток стане доступним за адресою `http://localhost:5173/`.*

4. **Перевірка лінтером:**
   ```bash
   npm run lint
   ```

5. **Збірка для production:**
   ```bash
   npm run build
   ```
   *Зібрані оптимізовані файли розміщуються у директорії `dist/`.*

6. **Попередній перегляд зібраного проєкту:**
   ```bash
   npm run preview
   ```

## 🔄 Робочий процес (Workflow) додавання нової роботи

Додавання нової шкільної роботи в портал реалізовано за зрозумілою та повторюваною схемою:

1. **Створення компонента роботи:**
   Створіть файл у папці `src/pages/MyNewWork.jsx`. Огорніть вміст у компонент `<WorkShell>` для стандартизованого вигляду, хлібних крихт та структури.

2. **Стилізація:**
   Створіть `src/styles/MyNewWork.css` із семантичними класами для таблиць, списків або ілюстрацій, та підключіть його у `src/main.jsx`.

3. **Реєстрація метаданих:**
   У файлі `src/data/works.js` додайте запис у масив `works`:
   ```javascript
   {
     id: 'my-new-work',
     subject: 'geography', // або 'biology' / 'ukrainian-language'
     slug: 'my-new-work',
     path: '/geography/my-new-work',
     title: 'Назва роботи',
     shortTitle: 'Коротка назва',
     description: 'Короткий опис для картки та метаданих.',
     documentTitle: 'Назва роботи | Предмет | Синапс',
   }
   ```

4. **Підключення маршруту:**
   У `src/App.jsx` зареєструйте новий роут всередині `<Route element={<AppShell />}>`:
   ```jsx
   <Route path="/geography/my-new-work" element={<MyNewWork />} />
   ```

*Робота автоматично з'явиться у списку відповідного предмету та отримає повну підтримку колірних тем і навігації.*

## 🌐 Деплоймент (Vercel)

Проєкт налаштовано для миттєвого розгортання на платформі [Vercel](https://vercel.com).
Для коректної роботи React Router у режимі клієнтського роутингу (Single Page Application) файл `vercel.json` спрямовує всі запити на `index.html`:

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```
